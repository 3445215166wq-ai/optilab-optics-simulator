# 光学计算原理说明 OptiLab — Optics Reference

本文档记录 OptiLab 各模块的**物理模型、公式推导、符号约定、单位与数值保护策略**，对应源码中的中文注释。
所有结论均可由 `npm test` 中的单元测试复算验证（见 [`TESTS.md`](TESTS.md)）。

---

## 0. 全局约定

### 0.1 单位

| 物理量 | 单位 | 说明 |
| --- | --- | --- |
| 长度（焦距、物距、像距、物高、孔径、波长换算后的几何量） | **mm** | 全项目统一，避免 m/mm 混用 |
| 波长 | **nm** | 仅在需要显示介质中波长时参与换算 |
| 角度（界面显示） | **°** | 内部计算统一先转弧度 |
| 折射率、放大率、F/#、R/T、NA | 无量纲 | — |

### 0.2 坐标系

- 光轴方向为 `x`（代码中亦以 `z` 作轴名显示），向右为正；垂直光轴方向为 `y`，向上为正。
- 画布屏幕坐标 `y` 向下为正，由 `render/viewport.ts` 统一取负号处理，物理层不感知屏幕坐标。

### 0.3 数值保护

| 风险 | 处理 |
| --- | --- |
| 除零（`u = f`） | 判定为「成像于无穷远」，`distance = null`，不返回 1e9 之类的假值；同时给出显式警告 |
| `asin` 定义域越界（全反射） | 先判断 `sinθ₂ > 1 + 1e-12`，是则标记全反射并令 `θ₂ = null`，不进入 `asin` |
| 极端像距 | 超过 3×10⁵ mm 视为无穷远（仅用于避免绘制与图表数值爆炸） |
| `NaN / Infinity` 传播 | 核心层校验输入并返回 `{ok:false, errors}`；格式化层把 `null/NaN/∞` 显示为 `—` / `±∞` |
| 视口退化（宽或高为 0） | `planScale()` 给最小跨度，缩放上限 400 px/mm |

## 1. 模块一：几何光学与薄透镜成像

### 1.1 模型与近似

1. **薄透镜（thin lens）**：忽略透镜厚度，把光在前后表面的两次折射等效为主平面上的一次偏折。
2. **近轴近似（paraxial）**：只考虑与光轴夹角很小的光线，`sinθ ≈ tanθ ≈ θ`，使成像关系线性化，因而**模型内不存在像差**。
3. **符号约定（实物正距离约定）**：
   - 物距 `u > 0`（物体恒在透镜左侧）；
   - 焦距 `f` 带符号：**凸透镜（会聚）`f > 0`，凹透镜（发散）`f < 0`**；
   - 像距 `v > 0` 表示像在透镜右侧（实像），`v < 0` 表示像在左侧（虚像）。

### 1.2 核心公式

由主平面偏折矩阵（近轴）：

```
[y₂]   [ 1      0 ] [y₁]
[  ] = [          ] [  ]
[u₂]   [−1/f    1 ] [u₁]        u 为近轴斜率（角度）
```

消去角度即得 **高斯成像公式**：

```
1/f = 1/u + 1/v      ⇒      v = f·u / (u − f)
```

**横向放大率**（像高 / 物高）：

```
m = h′/h = −v/u
```

**牛顿公式**（以焦点为原点，`x = u − f`、`x′ = v − f`）：

```
x · x′ = f²
```

代码中实现的是高斯公式，牛顿公式用于**单元测试的独立互校**（两条不同来源的公式给出同一结果，才算实现正确）。

### 1.3 成像情形分类（模型可精确给出的结论）

| 条件 | 像距 v | 放大率 m | 性质 | 工程对应 |
| --- | --- | --- | --- | --- |
| `u > 2f` | `f < v < 2f` | `−1 < m < 0` | 缩小、倒立、实像 | 相机、人眼 |
| `u = 2f` | `v = 2f` | `m = −1` | 等大、倒立、实像 | 1:1 成像、翻拍 |
| `f < u < 2f` | `v > 2f` | `m < −1` | 放大、倒立、实像 | 投影、显微物镜 |
| `u = f` | `v → ∞` | — | 出射平行光 | 准直器 |
| `u < f`（凸） | `v < 0` | `m > 1` | 放大、正立、虚像 | 放大镜 |
| 任意 `u > 0`（凹，`f < 0`） | `v < 0` | `0 < m < 1` | 缩小、正立、虚像 | 发散镜、眼镜 |

**为什么实像必倒立、虚像必正立**：由 `m = −v/u`，实像 `v > 0 ⇒ m < 0`；虚像 `v < 0 ⇒ m > 0`。这是单薄透镜的必然结果，不是经验规律。

### 1.4 光线追迹（本模块的实现方式）

薄透镜近轴模型下，从物点 `(x = −u, y = h)` 出发的**任意**光线经透镜后必然通过像点 `(v, h′)`（实像）或其反向延长线通过像点（虚像）。因此只要知道光线在透镜平面上的高度 `y_L`，即可写出出射方向：

```
k = (h′ − y_L) / v          （有限像距）
k = −h / u                  （v → ∞：全部出射光线平行于「过光心光线」）
```

由此构造三类光线（代码 `core/optics/thinLens.ts`）：

1. **三条主光线**
   - 平行光轴光线：`y_L = h`，出射后过像方焦点 `F′(z = +f)`；
   - 过光心光线：`y_L = 0`，方向不变；
   - 过物方焦点光线：入射直线过 `F(z = −f)`，`y_L = −h·f/(u − f)`，出射平行于光轴。
2. **光锥采样光线**：在通光口径 `±D/2` 内均匀取 `N`（奇数，保证有一条过光心）条，用于展示「光锥成像」与口径的关系。
3. **虚像延长线**：虚像情形下把出射段反向延长到画面左边界，并以 `dashed: true` 标记；渲染层据此画虚线，**物理层与显示层职责分离**。

**孔径遮挡（vignetting）**：`|y_L| > D/2` 的主光线标记 `blocked`，界面打叉并提示——说明真实系统中这些光线会被镜框拦住（理想薄透镜模型下像位置不受影响，只影响光通量与照度）。

### 1.5 由模型派生、并在界面上给出的量

| 量 | 公式 | 说明 |
| --- | --- | --- |
| 名义 F 数 | `N = |f| / D` | 按**无限共轭**定义，是镜头铭牌上的值；也是相对孔径 `D/f` 的倒数 |
| 有效 F 数 | `N_eff = |v| / D`（成实像时 `= N·(1+|m|)`） | 有限物距下真正决定像面照度（∝1/N_eff²）与衍射斑尺寸的量；两者只在无穷远成像时相等。**虚像时出射光发散，`N(1+|m|)` 关系不成立**，`N_eff` 仅作像方锥的等效量；成像于无穷远时无会聚锥，取 `null`（极限趋于 ∞） |
| 物方数值孔径 | `NA = n·sin(atan(D/2u))` | 严格定义含介质折射率 n，本模型默认空气（n ≈ 1）；近轴下用 tan 代 sin |
| 像方数值孔径 | `NA′ = n·sin(atan(D/2\|v\|))` | 成像于无穷远时出射光平行，会聚半角为 **0**（不是「无定义」），故 `NA′ = 0` |
| 会聚半角 | `θ = atan(D/2·距离)` | 与 NA 一一对应，界面同时给出角度便于直观理解 |

> 界面上的 `成像区间` 用 **`u/|f|`** 标注：凹透镜 `f < 0`，若写成 `u/f` 会得到负值，容易被误读为「物距为负」。

### 1.6 适用条件与局限

- 仅适用于**近轴、单色、薄透镜、无像差**的理想系统；`F/# < 1` 或大视场时必须引入实际光线追迹与像差理论。
- 不含衍射（实际成像分辨率受 `衍射极限` 约束，见阶段二）、不含镀膜与杂散光。
- 显示层为可读性对纵向做了有限拉伸（界面标注「纵向放大 N×」），**所有数值结果不受影响**。
- 本项目不构成商业光学设计依据。

## 2. 模块二：反射、折射与全反射

### 2.1 几何设定与公式

界面为水平线 `y = 0`，介质 1 在上（`y > 0`）、介质 2 在下（`y < 0`），光线自左上方向右下方入射到原点 `O`。角度一律**相对法线**度量。

```
反射定律：      θ₁′ = θ₁
折射定律(Snell)：n₁ · sinθ₁ = n₂ · sinθ₂   ⇒   sinθ₂ = (n₁/n₂)·sinθ₁
```

**全反射（TIR）**：只有当光从光密射向光疏（`n₁ > n₂`）时 `sinθ₂` 才可能超过 1；

```
临界角：θc = arcsin(n₂ / n₁)      （仅 n₁ > n₂ 时存在）
θ₁ > θc ⇒ 无折射光，能量 100% 反射
```

**布儒斯特角**：在此角度下 p 偏振反射率为零，反射光完全为 s 偏振。

```
θB = arctan(n₂ / n₁)
```

### 2.2 菲涅尔反射率（能量分配）

振幅反射系数（取最常见的正入射归一化形式）：

```
rs = (n₁cosθ₁ − n₂cosθ₂) / (n₁cosθ₁ + n₂cosθ₂)
rp = (n₂cosθ₁ − n₁cosθ₂) / (n₂cosθ₁ + n₁cosθ₂)
Rs = rs² ,  Rp = rp² ,  R = (Rs + Rp)/2   （自然光/非偏振）
T = 1 − R                                  （无吸收介质能量守恒）
```

**可验证的退化与极限**（均已写成断言）：

- 正入射 `θ₁ = 0`：`Rs = Rp = ((n₁−n₂)/(n₁+n₂))²`；
- 布儒斯特角：`rp = 0`，且 `θ₁ + θ₂ = 90°`；
- 全反射：`R = 1`、`T = 0`；
- 掠入射 `θ₁ → 90°`：`R → 1` 但始终 `< 1`；
- `n₁ = n₂`：`R = 0`、`θ₂ = θ₁`（界面等效不存在）。

**代码中的取舍**：TIR 情况下菲涅尔分支直接短路为 `R = 1`，不做复数振幅计算（不涉及相位与倏逝波），并在 `notes` 中说明这一简化。

### 2.3 介质参数与预设

介质折射率按**标称常数**（一般对应 587.6 nm 钠黄光 d 线）处理：

| 介质 | n | 备注 |
| --- | --- | --- |
| 真空 | 1.0 | 参考基准 |
| 空气 | 1.000293 | 15 ℃, 101.325 kPa |
| 水 | 1.333 | 20 ℃ 可见光 |
| 熔融石英 | 1.4585 | UV/IR 光学件 |
| 冕牌玻璃 BK7 | 1.5168 | 最常用光学玻璃 |
| 火石玻璃 F2 | 1.6204 | 高色散 |
| 蓝宝石 | 1.77 | 耐磨窗口 |
| 硅 | 3.48 | 红外（≈1550 nm），可见光不透明 |
| 金刚石 | 2.417 | 临界角极小（≈24.4°） |

派生显示量：介质中光速 `v = c/n`、介质中波长 `λ = λ₀/n`。

### 2.4 适用条件与局限

- 理想平面界面、各向同性、无吸收；**未计入色散**（所以改波长只影响介质中波长的显示，不改变折射角）；
- 不含表面粗糙度散射、镀膜多层干涉、倏逝波与相位突变；
- 界面与光线均为二维示意，不做三维锥形光束与偏振态演化。

## 3. 显示层示意与「真实计算」的边界

| 内容 | 性质 | 界面标注 |
| --- | --- | --- |
| 像距 / 像高 / 放大率 / 临界角 / 反射率 / 曲线数据 | **严格由公式实算** | 面板给出数值与计算过程 |

| 光锥光束填充 | 显示处理（7.5% 透明度包络面） | 绘制层级低于典型光线、透镜与文字标注 |

> 这样保证辅助信息永远不会盖住成像结论。

## 4. 模块三：衍射与光学分辨率（已实现）

### 4.1 模型与公式

均匀照明、直径 D 的**理想圆孔**在焦平面上的夫琅禾费衍射（艾里斑）：

```
I(r) = I₀ · [ 2·J₁(v) / v ]² ,   v = π·D·r/(λ·f) = π·r/(λ·N)
```

| 结论 | 公式 | 备注 |
| --- | --- | --- |
| 第一暗环（艾里半径） | `r₁ = 1.2197·λ·N ≈ 1.22λN` | 系数来自 J₁ 的第一零点 3.8317/π |
| 第二暗环 | `2.2331·λ·N` | J₁ 第二零点 7.0156/π |
| 第一副极大 | `1.6347·λ·N`，强度 **1.75%** | 由程序在暗环之间数值搜索得到，非查表 |
| 瑞利判据 | `Δ = r₁` | 两点间距等于第一暗环半径时「刚好可分辨」 |
| 非相干截止频率 | `ν_c = 1/(λ·N)` [lp/mm] | ≈ 2NA/λ（近轴） |
| 数值孔径 | `NA′ ≈ D/(2f) = 1/(2N)`，`NA = |m|·NA′` | 严格定义含折射率：NA = n·sinθ |

### 4.2 物方与像方（最易出错的地方）

`r₁ = 1.22λN` 默认是**像方**（传感器平面）量。物方对应量为 `r₁/|m|`，截止频率为 `ν_c·|m|`。
界面把「像方艾里半径 / 物方艾里半径 / 像方截止频率 / 物方截止频率」并列显示，避免混用。

### 4.3 数值实现

- `J₁(x)` 用 Numerical Recipes 的分段有理逼近（|x|<8 多项式比，|x|≥8 渐近展开）；
  单元测试对照 J₁ 的三个零点、首个极大值与级数展开，主区间相对误差约 1e-8。
- 二维图样由 `sampleAiryImage(256²)` 逐点求值后经有序色阶上色（线性/对数两种映射）。
- 剖面曲线 320 点、家族曲线 160 个 F 数采样点，全部实算。

## 5. 模块四：PSF 与 MTF（已实现）

### 5.1 复光瞳与计算链路

```
P(ρ) = circ(ρ)·exp[i·2π·W₂₀·ρ²]        ρ = r/a ∈ [0,1]
PSF  = |FT{P}|²
OTF  = FT{PSF} / FT{PSF}(0) ,  MTF = |OTF|
```

- **离焦波像差 W₂₀**：光瞳边缘相对中心的附加光程差，单位为波长 λ；二次型来自「离焦改变波前曲率」。
- 与像面纵向偏移的关系：`W₂₀ = Δz/(8λN²)`，即 `Δz = 8λN²W₂₀`；
  代入 `W₂₀ = 0.25` 得 `Δz = 2λN²` —— 这正是经典焦深判据 ±2λN²。
- **轴上零点**：硬边圆孔纯离焦时轴上振幅 ∝ `(e^{i2πW₂₀} − 1)`，
  故 W₂₀ = 1λ、2λ… 处轴上强度严格为 0（界面在 W₂₀=1λ 时斯特列尔比 ≈ 1e-6 是正确结果，不是数值错误）。
- 斯特列尔比取 `S = |ΣP|²/(Σ|P|)²`，对**轴上峰值**精确（无需第二次 FFT）。

### 5.2 数值标定（否则 MTF 横轴会错）

设网格 n×n、光瞳半径占 R 个采样点（默认 n=256，R=25）：

```
像面采样间距  dx = 2R·λ·N/n
频率分辨率    dν = 1/(n·dx) = 1/(2R·λ·N)
截止频率      ν_c = 1/(λ·N)          ⇒  dν/ν_c = 1/(2R)（频点数只由 R 决定）
奈奎斯特      ν_N = n/(4R·λ·N)       ⇒  ν_N/ν_c = n/(4R)（需 > 1）
```

默认参数下：dx ≈ 0.86 μm、每个艾里半径约 6.25 个采样点、截止频率内 50 个频点、ν_N/ν_c ≈ 2.56。

### 5.3 验证（数值 vs 解析）

| 检查 | 解析基准 | 实测偏差 |
| --- | --- | --- |
| W₂₀ = 0 的 PSF 主瓣截面 | 艾里斑 `[2J₁(v)/v]²` | 每点绝对偏差 ≈ 0.004 |
| W₂₀ = 0 的 MTF | `(2/π)[arccos t − t√(1−t²)]` | 最大偏差 < 1.5% |
| MTF50 | 解析曲线插值 | 相对偏差 < 2% |
| 焦深判据 | `W₂₀ = 0.25 ↔ Δz = 2λN²` | 完全一致 |
| 离焦对称性 | MTF(+W₂₀) = MTF(−W₂₀) | 一致 |

开发过程中遇到并修掉的两个标定问题（已写入测试注释）：
1. 光瞳圆边界若只用一圈线性斜坡，会系统性缩小有效口径 → 改为 **4×4 子采样面积占比**；
2. 径向平均若用「环带几何中点」当半径，整数半径上像素分布不均会让 PSF 看起来宽 10% →
   改为**该环带内实际像素的平均半径**。

## 6. 模块五：自动对焦与设备性能测试（已实现）

### 6.1 虚拟设备与退化模型

台架是**仿真**的虚拟 Z 轴平台 + 相机，没有实体硬件。成像链路：

```
靶标 → 离焦高斯模糊 → 曝光（增益/偏置）→ 传感器高斯噪声（带种子）
```

**离焦用高斯模糊近似**：`σ = 模糊系数 × |z − z_focus|`。这是**图像退化近似模型**，
不是严格物理光学（真实离焦 PSF 见模块四：会出环、旁瓣乃至轴上零点）。
选择高斯近似的原因：本模块考核的是「评价函数 + 搜索策略 + 重复性统计」这套工程流程，
高斯退化单调可控、计算量可接受。

### 6.2 清晰度评价函数

| 指标 | 公式 | 特点 |
| --- | --- | --- |
| Laplacian Variance | `L = I(x±1,y)+I(x,y±1)−4I(x,y)`，`score = Var(L)` | 二阶差分，对噪声最敏感，实现最简单 |
| Tenengrad | `score = mean(Gx²+Gy²)`（Sobel） | 一阶梯度能量，抗噪与灵敏度均衡，工程常用 |
| Brenner | `score = mean([I(x+2,y)−I(x,y)]²)` | 只看水平跨 2 像素差分，计算最省 |

三者都随离焦单调下降、峰在焦平面；**绝对值不可跨图比较**，只比较同图不同退化的曲线形状。

### 6.3 搜索策略

- **全范围遍历**：步长 `s` 扫过范围 `R`，捕获次数 `R/s + 1`，最可靠。
- **粗调 + 精调**：先用 `4s` 粗扫定位，再在最优点 `±1` 个粗步长内用 `s` 精扫，捕获次数显著减少。
- 关键性质：焦平面附近评分曲线是**平顶**的，因此「误差 ≤ 一个步长」是正常结论；
  想要更准需减小步长或做亚步长抛物线插值。

### 6.4 误差模型与统计指标

- **定位误差**：`z_actual = z_cmd + U(−e, +e)`，e 由界面设定；
- **噪声**：带种子 PRNG，噪声种子与位置绑定 → 同一位置重复拍摄得到同一帧（实验可复现）；
- **重复性测试**：每次实验起始位置在 `±范围/4` 内随机、噪声种子不同，统计
  平均误差 / 最大误差 / 标准差 / 成功率 / 平均捕获次数 / 平均耗时；
- **PASS/FAIL**：`|bestZ − z_true| ≤ 阈值` 判 PASS。

术语区分：**准确度**（与真值的偏差）、**重复性**（多次之间的一致性，看标准差）、
**稳定性**（跨时间/条件的一致性，本平台不模拟时间漂移）。

## 7. 模块六：工业视觉成像质量测试（已实现）

### 7.1 退化链路（按物理顺序）

```
照度不均（余弦暗角）→ 对比度（围绕 0.5 缩放）→ 光学模糊（离焦高斯 / 运动线段 PSF）
→ 曝光（out = in·gain + offset，截断到 [0,1]）→ 传感器高斯噪声（带种子）
```

过曝是**截断**，高光细节不可恢复；欠曝是信噪比下降，可通过增益部分补偿 —— 两者不可逆程度不同。

### 7.2 指标

| 指标 | 公式 | 单位/范围 | 陷阱 |
| --- | --- | --- | --- |
| 平均亮度 | `mean(I)` | 0–1 | 只反映整体明暗 |
| RMS 对比度 | `stdDev(I)` | 0–0.5 | 与图像内容相关 |
| 清晰度 | Laplacian / Tenengrad / Brenner | 无量纲 | 只能同图比较 |
| MSE | `mean[(I_ref−I_test)²]` | ≥0 | — |
| PSNR | `10log₁₀(1/MSE)` | dB，相同为 +∞ | 对亮度偏移敏感、对轻度模糊不敏感 |
| SSIM | 11×11 高斯窗、`C₁=(0.01)²`、`C₂=(0.03)²` | 1 = 完全相同 | 对亮度/对比度变化更宽容 |
