# 演示指南 · 怎么把 OptiLab 展示给别人

> 读者：面试官 / 导师 / 同学。目标：**3 分钟内让对方看懂「这不是画图作业，是一套能验证的仿真 + 测试工具」**。

---

## 1. 三种展示形态，按场合选

| 形态 | 适合场合 | 现状 | 需要准备 |
| --- | --- | --- | --- |
| **A. 在线可交互**（主推） | 面试现场投屏、简历/微信发链接、导师自己点开看 | ⚠️ 目前只有本地 dev server | 部署到 GitHub Pages（步骤见 §2） |
| **B. 静态材料** | 离线兜底、邮件附件、作品集 PDF | ✅ 已生成 `docs/samples/` | 每次改版后重新导出（见 §6） |
| **C. 口述脚本** | 面试时没网/没时间开电脑 | ✅ 见 §3 | 记住 4 个动作 + 每句要说的点 |

**建议组合**：A 为主（现场点），B 兜底（网断了直接放 PDF），C 打底（怎么问都能讲）。

## 3. 三分钟演示路径（照着点就行）

**开场一句话**：「这是一个纯前端的光学仿真平台，7 个实验模块 + 1 个知识库，所有计算在浏览器本地完成，197 个单元测试保证物理正确性。」

| 时间 | 动作 | 要说的点 |
| --- | --- | --- |
| 0:00–0:40 | 打开 **几何光学**，点预设「u < f · 放大镜虚像」 | 「像变成了虚像：像距 −150 mm、放大 2.5 倍，虚线是**反向延长线**。拖动物距跨过 u = f 时，程序不会给出一个假的巨大像距，而是判定『出射平行光、像在无穷远』。」 |
| 0:40–1:20 | 切到 **PSF / MTF**，先看 W₂₀=0，再点预设「明显离焦 0.5λ」 | 「MTF 曲线是复光瞳做二维 FFT 算出来的。**关键是这条绿色虚线是解析衍射极限公式**——数值解和解析解差 <1.5%，这就是我的验证方式。离焦后高频先塌。」 |
| 1:20–2:10 | 切到 **自动对焦**，点「执行自动对焦」→ 再点「重复性测试 ×5」 | 「虚拟 Z 轴平台扫 22 次、140 ms 找到焦点，误差 116 μm，阈值 150 μm → **PASS**。单次结果不算数，所以再做 5 次统计：平均误差、标准差、成功率——这就是设备验收的思路。」 |
| 2:10–2:50 | 切到 **测试报告**，讲记录从哪来 → 点「打印 HTML 报告」 | 「每个模块点『记录实验』就把参数、结果、判定、异常、模型局限存成一条结构化记录；这里能导出 CSV/JSON/PNG，并能直接打印成正式报告（六段结构：目的/依据/参数/结果/误差/结论+局限）。」 |
| 2:50–3:00 | 收尾 | 「模型局限我写在每个模块里：这是理想薄透镜/解析艾里斑模型，不是 Zemax；离焦用高斯近似时会明确标注『图像退化近似』。**不吹自己没做的事**。」 |

## 4. 八分钟深度版（技术面用）

在 §3 之后追加两条：

1. **打开 `src/core/optics/psfMtf.ts`**：讲光瞳构建（4×4 子采样抗锯齿）、坐标标定 `dx = 2RλN/n`、以及为什么 MTF 横轴容易错。
2. **终端跑 `npm test`**：197 个用例 3 秒跑完，指出 `psfMtf.test.ts` 里「数值 MTF vs 解析 OTF」那条断言——**先用解析解校准数值引擎，再让它算没有解析解的离焦**。

## 5. 常被追问的 6 个问题（配答要点）

| 追问 | 答法要点 |
| --- | --- |
| 「这些图是不是用库画的？物理是真的吗？」 | 物理纯自己写（`core/` 下无 Vue/DOM 依赖，可 Node 单测）；ECharts 只负责画曲线，Canvas 只负责画光路。自实现 radix-2 FFT 与 J₁ 贝塞尔。 |
| 「你的 MTF 凭什么可信？」 | 与解析衍射极限 `(2/π)[arccos t − t√(1−t²)]` 对照，最大偏差 <1.5%；W₂₀=0 时 PSF 与解析艾里斑主瓣偏差 ≈0.004。 |
| 「离焦是物理算的吗？」 | 模块四（PSF/MTF）是复光瞳 FFT 严格模型；模块五/六的高斯模糊是**图像退化近似模型**，界面明确标注，因为它考核的是对焦流程而不是 PSF 形状。 |
| 「接 AI 了吗？准确率多少？」 | **没有接**，接口（`DetectorAdapter`）已预留但调用即抛错。没有真实模型和标注就不给准确率——这是项目的硬性红线，也是我理解的工程诚实。 |
| 「性能怎么样？会不会卡？」 | 单帧退化 ~2 ms（拖 Z 实时）；一次对焦搜索 22 帧 / 140 ms；PSF 两次 256² FFT ~20 ms；SSIM 批量扫描 13 点 ~1.5 s（按钮上有「扫描中」态）。 |
| 「给客户/别人用安全吗？数据传哪儿了？」 | 纯静态站点，**没有任何后端**：记录与日志只存在访问者自己浏览器的 localStorage，上传的图片只在本地 canvas 处理，一张都不会离开本机。界面和 README 都写明了这一点，并提供 JSON 备份/导入。 |
| 「你觉得哪里做得不够？」 | 缺实际像差（只有离焦）、无 Worker 并行、E2E 还是临时脚本、没做真机部署验证。这些都写进了 README 的「项目局限」。 |

## 6. 静态材料（`docs/samples/`，随时可直接发给别人）

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `optilab-sample-report.pdf` | **4 条真实实验记录的完整测试报告**（几何光学虚像 / 衍射 F22 / 自动对焦 PASS / 成像质量离焦） | 作品集附件、邮件、面试兜底 |
| `optilab-sample-report.html` | 同一份报告的可打印 HTML（浏览器打开 Ctrl+P 即可转 PDF） | 想自己改样式/截图时用 |
| `optilab-records-summary.png` | canvas 现画的记录汇总图（含 PASS 色标） | 贴进 PPT/Notion |
| `report-overview.png` | 测试报告模块界面截图 | 作品集配图 |

> 这些样本是用脚本在真实运行的程序里点出来、导出生成的（4 条记录、含 PASS 判定），不是手写的图片。

**重新生成**：跑一遍 `npm run dev`，按 §3 在四个模块各点一次「记录实验」，再到报告页导出即可；或让我用 Playwright 脚本重跑。
