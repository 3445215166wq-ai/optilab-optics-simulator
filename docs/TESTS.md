## 1. 验证策略

单元测试的目的不是「跑一遍看不报错」，而是**证明实现与理论一致**。本项目采用三类可独立推导的判据：

| 判据类型 | 做法 | 例子 |
| --- | --- | --- |
| **解析解对照** | 用另一个独立公式算同一个物理量，两者必须相等 | 高斯公式 vs 牛顿公式 `(u−f)(v−f) = f²`；`v = f·u/(u−f)` vs `1/(1/f − 1/u)` |
| **物理不变量** | 与具体实现路径无关的守恒/对称性质 | 斯涅尔等式残差 `< 1e-12`；`R + T = 1`；光路可逆；所有出射光线必过像点 |
| **极限与退化** | 已知的边界行为 | `θ₁ = 0` 时 `R = ((n₁−n₂)/(n₁+n₂))²`；`u → ∞` 时 `v → f`；全反射时 `θ₂ = null`、`R = 1` |

**刻意不使用的方式**：与「上一次输出」做快照对比——实现有错时快照会一起错，无法发现回归。

## 3. 开发过程中的「测试先失败」记录（真实性说明）

首轮运行 64 例中有 6 例失败，**全部是测试期望值本身写错**，实现经手算复核无误，逐条修正后通过：

| 失败用例 | 原因 | 修正 |
| --- | --- | --- |
| 空气→水 45°，期望 32.0338° | 我漏乘了 `n₁ = 1.000293`，正确值 `32.0472°` | 改为 32.0472，并在测试里写下算式 |
| BK7→空气临界角期望 41.2° | 容差给的是 0.05° 但真值 41.2599° | 改为 `toBeCloseTo(41.26, 2)` |
| 擦界面出射期望 89.9996° ≈ 90° | `θc − 1e−9` 在 `asin` 附近放大成 3.6e−4°，双精度决定的 | 改为断言 `> 89.9` 且 `≤ 90` |
| 掠入射 `R > 0.99` | 89.9° 的真值是 0.98991（物理正确） | 改为对照 0.98991 并断言严格 `< 1` |
| `u = 1e5` 时期望 `v ≈ 100 ± 0.0005` | `v = f/(1 − f/u)` 本身就是 100.1001（偏离 0.1%） | 改为与解析式对齐 + 相对偏差 `2e-3` 检查 |
| `approxEqual(1e-9, 0)` 期望 true | 默认绝对容差是 1e-12 | 改为 `1e-13` 为 true、`1e-9` 为 false |

阶段二又出现两轮同类失败，同样是**判据/期望值**问题而非实现错误：

| 失败用例 | 原因 | 处理 |
| --- | --- | --- |
| 小参数 J₁ 级数展开 `toBeCloseTo(…, 10)` | 分段有理逼近在 x≈0.2 处本身有 ~7e-10 误差 | 改为断言**相对误差 < 1e-7**（与实现精度声明一致） |
| 「换段处连续」 | |x|=8 附近两段各有 ~1e-4 绝对误差（NR 逼近固有限制） | 改为与参考值 J₁(8)≈0.234636 对照 |
| 高阶零点 `j1Zero(k)` | 渐近式写错成 `(k+0.75)π`，正确是 `(k+ν/2−1/4)π = (k+0.25)π` | 修正公式，k=4 时 13.3237 与真值一致 |
| `f_c ≈ 2NA/λ`（N=2 时偏差 3%） | 该关系只在近轴成立 | 拆成两条断言：N≥4 时 <1%；N=2 时**故意断言偏差 >2%**，把「近轴近似会退化」写进测试 |
| 数值 PSF 比解析艾里斑「宽 10%」 | 不是物理模型问题，而是统计方法：径向分箱用「环带几何中点」当半径，整数半径上像素分布不均 | 改用**环带内实际像素平均半径**；另把光瞳边缘改为 4×4 子采样面积占比。修正后主瓣绝对偏差从 0.06 降到 0.004 |

结论：这一轮失败恰恰说明了「与理论对照」的价值——是我记错了公式细节，而不是代码算错了。

## 6. 如何新增测试

```ts
// src/core/optics/<name>.test.ts
import { describe, expect, it } from 'vitest'
import { computeXxx } from './xxx'

describe('computeXxx — <物理判据>', () => {
  it('<可独立推导的结论>', () => {
    const r = computeXxx({ /* 参数 */ })
    // 优先断言物理不变量 / 解析解，并写出手算过程作为注释
    expect(r.someValue).toBeCloseTo(expected, 6)
  })
})
```

要求：

1. 每个断言都要能说出「为什么应该是这个值」，注释里写清算式；
2. 覆盖至少一个**退化/极限**情形（除零、全反射、零值、无穷远）；
3. 非法输入必须验证 **不抛异常且返回结构化错误**。
